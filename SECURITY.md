# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** — do not open a public
issue for them.

- **Contact:** create a private advisory in this repository (GitHub
  Security → Report a vulnerability), or email the QYVORA OffSec team at
  **qyvorasec@gmail.com**.
- **What to include:**
  - affected version / commit,
  - description of the issue and its impact,
  - steps to reproduce,
  - any suggested mitigation.

## Supported versions

The latest release and the `main` branch are supported. Security fixes land
in the next release and are backported only to the latest release branch.

## Our commitment

- We will acknowledge your report within 3 business days.
- We will provide a status update within 10 business days.

## Authorized use

SEKHMET is an **authorized** fuzzing and vulnerability-discovery framework.
It is not an unauthorized-access or persistence tool. Use it only against
systems you are explicitly authorized to test. See
[docs/Security-Model.md](docs/Security-Model.md) for the authorization model
and [docs/Safety-Model.md](docs/Safety-Model.md) for operational guards.
