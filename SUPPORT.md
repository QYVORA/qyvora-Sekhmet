# Support

## Documentation

Start with the `docs/` directory and the README. The
[Security Model](docs/Security-Model.md) and [Safety Model](docs/Safety-Model.md)
are required reading before running campaigns against anything other than a
local simulated target.

## Getting help

- Open an issue for bugs and feature requests (see
  [CONTRIBUTING.md](CONTRIBUTING.md)).
- The repository is hosted under `github.com/QYVORA/qyvora-sekhmet`. For
  issues on other QYVORA projects, use their respective repositories.
- Report security vulnerabilities privately per [SECURITY.md](SECURITY.md) —
  never in a public issue.

## Operating responsibility

SEKHMET is an **authorized-use** tool. Fuzz only targets you are specifically
allowed to exercise. Local targets are scoped to the declared path; remote
targets require explicit authorization acknowledgement. Review the Security
and Safety models before running it in an organization.
